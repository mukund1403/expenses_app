# Expenses App
App that automates expense tracking by auto forwarding transaction alert emails

## Quick Start Guide
1. Pull the repo
2. For frontend:
   - `cd frontend`
   - `npm install`
   - `npm run dev`
3. For backend:
   - `cd backend`
   - `go run .`
