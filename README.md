# Expenses App
App that automates expense tracking by auto forwarding transaction alert emails

## Quick Start Guide
1. Pull the repo
2. For frontend:
   a. `cd frontend`
   b. `npm install`
   c. `npm run dev`
3. For backend:
   a. `cd backend`
   b. `go run .`
